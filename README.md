# 精料库 · 元件库管理系统

一个本地离线的元件库存 + 封装速查工具。用 Python + tkinter 写的，数据存 SQLite，不联网、启动快、随手查。

主要用来解决：手上散装元件太多、经常要查价格、查封装、批量改价，懒得开 Excel 的场景。

## 功能

### 元件管理
- 增删改查，支持批量文本录入（空行分隔多个元件）
- 从剪贴板一键填充（自动清洗 AI 回复里的 markdown 包装）
- 双击打开购买链接，右键快速改价格 / 改链接
- 电压 / 电流 / 功率等规格字段，主表"规格"列分多行显示

### 封装速查
- 关键词搜封装名，双击复制，可直接贴到嘉立创 EDA / KiCad
- 封装可手动添加、编辑、删除
- 支持 CSV 批量导入导出
- 表格显示自动换行、行高自适应、带网格线

### 智能导入
- 一个按钮自动识别 CSV 类型：**嘉立创 BOM** 或 **封装库**
- BOM 导入自动解析 Comment 里的电压 / 电流 / 功率
- 按立创编号 / 型号去重，新旧数据比对"完整度"决定是否覆盖
- 导入报告列出：新增 N 条 / 更新 M 条 / 跳过 K 条 / 未匹配明细

### 参数匹配
- 按立创编号 / 精确型号 / 通用描述 / 多关键词组合匹配元件
- 支持批量粘贴，一次匹配多个

### 项目管理
- 与元件表**完全独立**的多对多关联，删项目不影响元件，删元件自动解除关联
- 一个元件可以同时属于"拓展坞""维修电源"等多个项目
- 主界面顶部下拉切换项目，支持手输模糊匹配（打"拓"自动过滤）
- 可记用量和备注（如 C1, C2, C3）

### 批量操作
- **批量改价**：一次给多个元件更新价格
- **批量加入项目**：文本导入模式，支持 `x3` / `*3` / `3个` 各种用量写法
- **价格校准**：列出超过 15 天没更新价格的元件
- **导出数据**：一键复制为 CSV 或 JSON 到剪贴板

### AI 协作
- 一键复制规范化的 AI 提示词，让 AI 按固定格式生成数据
- 可选择附加本地文档，提示词 + 文档内容一起复制给 AI
- 生成的文本直接粘回软件即可批量入库

### 界面
- 深色主题为主，支持多主题切换
- 表格控件自研（`WrappedTable`），支持单元格自动换行、行高按内容自适应

## 环境要求

- Python 3.10 或以上
- Windows 官方 Python 自带 tkinter，无需额外安装

本项目**只用 Python 标准库**，不需要 `pip install` 任何第三方包。
